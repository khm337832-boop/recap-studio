ဖန်တီးမှု Tools

သင်၏ workspace

🎬 Video Workspace

သင့်ဖုန်းထဲက ဗီဒီယိုကို ရွေးပြီး preview ကြည့်နိုင်ပါတယ်။ ဖိုင်ကို server သို့ မပို့ပါ။

Subtitle Studio တွင် ထည့်ထားသော စာတန်းများကို ဗီဒီယိုပေါ်တင်ပြီး WebM ဖိုင်အဖြစ် ထုတ်နိုင်သည်။ Chrome နှင့် ဖုန်း၏ recording ပံ့ပိုးမှုအပေါ် မူတည်သည်။ Export သည် ဗီဒီယိုကြာချိန်အတိုင်း ကြာမည်။

📝 Script & Voice

ကိုယ်တိုင်ရေးထားသော script ကို ဖုန်း၏ text-to-speech အသံဖြင့် နားထောင်နိုင်သည်။ မြန်မာအသံရရှိမှုသည် ဖုန်းပေါ်မူတည်ပါသည်။

💬 Subtitle Studio

စာသားနှင့် အချိန်များကို ကိုယ်တိုင်ဖြည့်ပြီး SRT ဖိုင် ဒေါင်းလုဒ်လုပ်ပါ။

စာတန်းမရှိသေးပါ။

✨ နောက်တစ်ဆင့် Features

AI script generation၊ AI voice ဖိုင်ထုတ်ခြင်း၊ အလိုအလျောက် subtitle၊ poster၊ batch processing နှင့် video render တို့ကို ယခုနမူနာတွင် မချိတ်ဆက်ရသေးပါ။ အချို့မှာ server၊ AI model သို့မဟုတ် API ကုန်ကျစရိတ် လိုအပ်နိုင်ပါသည်။

Video ကို ပြုပြင်ခြင်းသည် မူပိုင်ခွင့်အာမခံမပေးပါ။ အသုံးပြုခွင့်ရှိသော footage များကိုသာ အသုံးပြုပါ။
